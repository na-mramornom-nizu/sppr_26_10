Ноутбук [`sppr_tasks_2_1_2_10.ipynb`](sppr_tasks_2_1_2_10.ipynb) содержит постановки, модели Pyomo, результаты и ответы для защиты по упражнениям 2.1–2.10 методического пособия (с. 93–97). Для модулей в задачах 2.8 и 2.9 использован приём линеаризации с. 62–63. Задача 2.10 решена преобразованием Чарнеса—Купера.

Отдельный ноутбук [`sppr_bonus_energy.ipynb`](sppr_bonus_energy.ipynb) воспроизводит задачу выбора состава электростанций из § 3 методического пособия (с. 60–62, формулы (3.1)–(3.6)): минимизируются годовые эксплуатационные расходы при ограничениях на мощности, выработку и бюджет строительства. Численные данные синтетические, поскольку методичка даёт общую модель без коэффициентов. Показаны непрерывное решение и целочисленный план с проверкой ограничений; генератор ноутбука — `build_bonus_energy.py`.

## Запуск

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m jupyter lab sppr_tasks_2_1_2_10.ipynb
```

Для дополнительного задания: `python -m jupyter lab sppr_bonus_energy.ipynb`. Если JupyterLab ещё не установлен: `python -m pip install jupyterlab`. Можно открыть файлы в VS Code и выполнить все ячейки сверху вниз. Ноутбуки также содержат сохранённые результаты расчётов.

В упражнении **2.2** текст методички не сообщает расход древесины на стол и стул. В **2.8** не заданы численные времена пути и дедлайны. Для них приведены параметрические модели и функции расчёта; численный ответ возможен после уточнения входных данных. В 2.4 показаны LP-релаксация и целочисленный план рабочих.

Исходный генератор ноутбука — `build_notebook.py`. После его запуска сохранённые результаты исчезнут до повторного выполнения ячеек.

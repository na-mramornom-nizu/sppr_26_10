Ноутбук [`sppr_tasks_2_1_2_10.ipynb`](sppr_tasks_2_1_2_10.ipynb) содержит постановки, модели Pyomo, результаты и ответы для защиты по упражнениям 2.1–2.10 методического пособия (с. 93–97). Для модулей в задачах 2.8 и 2.9 использован приём линеаризации с. 62–63. Задача 2.10 решена преобразованием Чарнеса—Купера.

Отдельный ноутбук [`sppr_bonus_energy.ipynb`](sppr_bonus_energy.ipynb) использует ограничения задачи выбора состава электростанций из § 3 методического пособия (с. 60–62, формулы (3.2)–(3.6)). По требованию к дополнительному заданию исходная цель минимизации эксплуатационных расходов заменена дробным показателем выработки на рубль затрат первого года. Численные данные синтетические: в методичке приведена общая модель без коэффициентов. Для непрерывной задачи построены прямая LP после преобразования Чарнеса—Купера и двойственная LP, проверено равенство их оптимумов. Физически реализуемый целочисленный план рассчитан отдельно методом Динкельбаха. Генератор ноутбука — `build_bonus_energy.py`.

## Запуск

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m jupyter lab sppr_tasks_2_1_2_10.ipynb
```

Для дополнительного задания: `python -m jupyter lab sppr_bonus_energy.ipynb`. Если JupyterLab ещё не установлен: `python -m pip install jupyterlab`. Можно открыть файлы в VS Code и выполнить все ячейки сверху вниз. Ноутбуки также содержат сохранённые результаты расчётов.

В упражнении **2.2** использованы уточнённые преподавателем нормы древесины: 15 футов на стол и 5 футов на стул. Для **2.8** в методичке не заданы численные времена пути и дедлайны, поэтому приведены параметрическая модель и функция расчёта. В 2.4 показаны LP-релаксация и целочисленный план рабочих.

Исходный генератор ноутбука — `build_notebook.py`. После его запуска сохранённые результаты исчезнут до повторного выполнения ячеек.
